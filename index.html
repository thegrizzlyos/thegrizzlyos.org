02 / Grizzly standalone

Try the tools on your own Debian based OS.

Grizzly's built-in developer friendly tools and apps can stand on their own paws, so users can bring useful pieces of Grizzly to the Debian based machine they already use - Ubuntu and Kubuntu for instance. This offers you a chance to get familiar with some of the cool aspects of the full Grizzly experience before you decide to switch.

⌘

Grizzly CLI

Inspect capabilities, validate Grizzly definitions, manage packages through typed operations, and review an append-only application history.

⌁

Grizzly MCP

Connect an MCP client to Grizzly’s explicit tools for system and repository work, with a narrow allowlist and typed requests.

↻

Grizzly Jobs

Define team practices in versioned .grizzly/jobs/ files, such as scheduled checks that enforce shared artifact-retention policies. Developers can discover, validate, and locally approve the same workflow.

▣

TileToShare

Share one selected window or tile as a virtual camera in a meeting, while keeping the rest of your desktop private.

04 / Notes

A safer, cleaner workspace

Grizzly keeps your host system focused while giving you room to choose how you build and run AI tools.

  • Container management: We recommend Portainer and Dozzle for Docker and log management (not included).
  • AI tools: Grizzly does not bundle any AI harness. Docker Sandbox is included and supports the major harnesses.
  • Safer development: Run agents in Docker Sandbox to reduce the risk of unintended changes to your system.
  • Keep the host clean: Install development toolchains in Docker Sandbox or use ready-made containers. Sandbox supports Docker in Docker, so you can run those containers inside it.
  • Choose your providers: A tool like Herdr (not included) wraps AI harnesses so you can mix model providers. Its plugins can also use Docker Sandbox to isolate agent work.
  • Disk encryption: Grizzly encrypts the full disk during installation. Enter your password at startup to unlock it, then go straight to the desktop. Encryption helps protect your data if the device is stolen.
