# Grizzly website

Live site: [https://thegrizzlyos.org](https://thegrizzlyos.org).

This repository contains the website source.

The landing page and its copy live in [`index.html`](index.html). Images and other static files live in [`assets/`](assets/).

## Preview locally

Open `index.html` in a browser, or serve the repository root:

```sh
python3 -m http.server
```

Then visit `http://localhost:8000`.
